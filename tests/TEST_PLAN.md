# Проверка AI Протоколиста на хакатоне

## Эталонные пары

| Вход | Эталон | Критичный минимум |
| --- | --- | --- |
| `Совещание №1.mp3` | `Протокол_совещания№1.docx` | 5 говорящих, 10 поручений, 2 темы |
| `Совещание №2.mp3` | `Протокол_совещания№2.docx` | 5 говорящих, 6 поручений, 4 доклада |

JSON в `tests/goldens/` выписан из двух предоставленных протоколов. Он не заменяет прослушивание аудио: соответствие текста эталона исходному звуку ещё следует проверить. Не публикуйте исходные записи без проверки прав и анонимизации.

## Как запускать проверку

1. Запустить существующие быстрые тесты: `python -m unittest discover -s tests -v`.
2. Обработать каждую исходную запись в приложении. Указать фактическую дату встречи, если она известна; иначе не превращать «до пятницы» в произвольную календарную дату.
3. Сохранить полный JSON карточки через `GET /api/meetings/{id}` в файл в локальной папке `.data/`.
4. Сравнить до ручных правок: `python tests/evaluate_goldens.py 1 .data/meeting-1-result.json` и так же для №2. Повторить после проверки секретарём.
5. Для каждого совпадения проверить аудио по времени реплики. Автоматическое сравнение по словам лишь предлагает соответствия; дополнительные поручения могут быть как ошибками ИИ, так и упущениями эталона.

## Приоритетные случаи

| Проверка | Ожидаемый результат |
| --- | --- |
| Руководитель произнёс поручение другому человеку | Говорящий и исполнитель различаются; исполнитель указан из смысла фразы. |
| В совещании №2 Ерлан получает поручение, но не говорит | Ерлан есть как исполнитель M2-01 и отсутствует среди говорящих. |
| «До пятницы», «к среде», «на следующей неделе» | Сохраняется исходная формулировка. Дата вычисляется только при известной дате совещания и ясном правиле отсчёта. |
| У M2-06 срок не указан | Поле срока пустое; система не назначает дату сама. |
| M2-05: смета за неделю, очередь закрыть за месяц | Два разных временных ориентира не смешиваются. |
| Повтор поручения в конце совещания | В итоговом списке одна актуальная запись, без дубля. |
| Отмена или изменение срока в речи | Итог содержит последнюю подтверждённую редакцию с ссылкой на реплику. |
| Саммари | Сохраняет цифры 71/8/60/11 в №1 и 94/68/12 в №2; не добавляет неподтверждённые факты. |
| Экспорт | PDF и DOCX открываются, содержат полное саммари, все утверждённые поручения, ответственных и сроки. |
| Закрытый контур | После подготовки моделей обработка записи проходит при заблокированном внешнем интернете; исходное аудио и транскрипт не уходят во внешние сервисы. |

## Дополнительные данные, которых пока нет

Два предоставленных совещания написаны преимущественно по-русски. Для обязательного требования по казахской и смешанной речи нужны отдельные записи с разметкой реплик и поручений. Для проверки Meet, Zoom и Teams нужны тестовые встречи каждой платформы. Для IoT нужны реальный микрофон, кнопка и индикатор либо честно обозначенная симуляция. Эти сценарии нельзя считать прошедшими по текущим двум файлам.

## Внутренний критерий готовности к показу

Оба файла обрабатываются от загрузки до экспорта без ручного вмешательства в код. До правок секретаря извлечено не менее 13 из 16 эталонных поручений; после проверки все 16 отражены корректно. Ни одно поручение не получает придуманного исполнителя или срока. Быстрые тесты и проверка JavaScript проходят. Это внутренний ориентир команды, а не официальная шкала жюри.
