# Пример экспорта

`sample-protocol.json` — полностью вымышленная учебная встреча: две темы, четыре реплики, два поручения. Текст написан для демонстрации и не является результатом распознавания или измерением качества ИИ. Реальные записи, имена и содержание протоколов организаторов здесь не используются.

- [Word](sample-protocol.docx)
- [PDF](sample-protocol.pdf)

Оба файла сформированы настоящими функциями `app.exports` с обычным шаблоном приложения. В шапке указана учебная организация, документ помечен как неутверждённый черновик. Сначала идёт текст по темам и говорящим, затем отдельное саммари и поручения. Точность реальных результатов оценивается отдельно в `tests/evidence`.

Повторить генерацию из корня проекта: `python scripts/export_example.py` (используйте Python среды приложения). DOCX и PDF содержат по две страницы. Все страницы обоих форматов отрисованы и визуально проверены 23 сентября 2026 года: текст и таблицы читаемы, обрезаний и наложений нет. Личные метаданные DOCX отсутствуют.
