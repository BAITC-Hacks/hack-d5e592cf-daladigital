## Формула автоматического назначения поручений

Перед выбором исполнителя система сначала определяет, является ли фрагмент настоящим поручением. Вопрос, предложение или фраза согласия сами по себе задачу не создают.

Для каждого возможного исполнителя `i` рассчитывается вероятность правильного назначения:

```text
z_i = θᵀx_i + x_iᵀAx_i
P_i = Calibrate(softmax_i(z))
i* = argmax_i P_i
```

`x_i` содержит сигналы из разговора и данных организации: прямое обращение, кто ответил на адресованный вопрос, соответствие роли, связь реплик, принятие обязательства, историю переназначений, а также качество распознавания речи и диаризации. `θ` — веса отдельных сигналов; `A` учитывает их сочетания. Параметры обучаются на размеченных примерах назначений и исправлений. `Calibrate` калибрует вероятности на отложенных размеченных данных.

Назначение принимается автоматически, когда ожидаемая цена ошибки меньше цены эскалации:

```text
(1 − P_i*) × C_ошибки < C_эскалации  → назначить i*
иначе                                  → назначить руководителю совещания
```

`C_ошибки` и `C_эскалации` задаются политикой организации. При отсутствии обучающих данных временно применяются объяснимые правила; их оценки помечаются как эвристические, а не как калиброванные вероятности.

В карточке задачи сохраняются исходная реплика, контекст, аудиофрагмент с таймкодом, выбранный исполнитель и основания назначения. Переназначение обновляет задачу и записывается как обучающий пример.
