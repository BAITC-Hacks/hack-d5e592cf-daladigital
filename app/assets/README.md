# Шаблон протокола

Обезличенные компоненты предоставленного образца: шапка, стили заголовков,
основной текст и трёхколоночная таблица поручений. Факты, имена и содержание
примеров в шаблон не включены. Части создаются по фактическим темам записи.
Поручения относятся к темам по источникам в транскрипте; неотнесённые элементы
остаются в общем разделе. Полный транскрипт добавляется по отдельному выбору.
