# Результаты двух предоставленных примеров

Снимок **существующих результатов**, сформированных локальным конвейером. Повторного распознавания и исправления результатов для красивых цифр не выполнялось. Скрипт открывает SQLite строго на чтение, публикует только метрики, хеш результата, отметку времени и количество событий аудита. Исходный звук, реплики, имена, формулировки поручений, ID встреч и пути не входят в отчёты.

| Показатель | Совещание 1 | Совещание 2 |
| --- | ---: | ---: |
| Поручений в эталоне | 10 | 6 |
| Извлечено поручений | 9 | 6 |
| Лексически сопоставлено | 6 | 5 |
| Предварительная полнота | 60% | 83,3% |
| Правильный исполнитель среди сопоставленных | 3 / 6 | 2 / 5 |
| Совпавший срок среди сопоставленных | 4 / 6 | 5 / 5 |
| Реплик в транскрипте | 33 | 20 |
| Голосовых меток / эталонных говорящих | 5 / 5 | 3 / 5 |
| Тем в саммари | 3 | 4 |

Это **лексический скрининг**, а не экспертная семантическая оценка, WER или DER. Он может пропустить корректный перефразированный текст и считать вариант написания имени расхождением. Для каждого сопоставления JSON сохраняет ID эталона, уверенность и признаки проверки; восстановить формулировки эталона можно из `tests/goldens`. Саммари здесь не оценивалось человеком. Полнота и правильность поручений требуют дальнейшей проверки даже при хорошем качестве саммари.

У №1 есть событие `extraction_refined`: это результат повторного уточнения поручений, а не первичный проход. У обоих результатов нет событий ручного редактирования в текущем журнале, но это само по себе не доказывает их полную неизменность. Точное происхождение и момент снимка сохранены в JSON. Файлы эталонов выписаны из DOCX организаторов и сами требуют сверки с аудио.

## Повторить на собственном локальном архиве

```bash
python scripts/evaluate_archive.py 1 /absolute/path/protocols.sqlite3 MEETING_ID --output tests/evidence/meeting_1.json
python scripts/evaluate_archive.py 2 /absolute/path/protocols.sqlite3 MEETING_ID --output tests/evidence/meeting_2.json
```

Используйте Python из установленной среды приложения. Полный диагностический отчёт с текстом можно получить локально через `tests/evaluate_goldens.py`, передав JSON встречи из API. Не добавляйте этот полный результат в Git без отдельного решения о публикации.
